### 2.4 `gravity_bias` は符号を持たない上向きの事前分布

`compute_gravity_bias = 0.20 × grv_lock + 0.15 × regime_fit − 0.10 × narrative_dispersion` は 3 項とも
`[0, 1]` の大きさの量で、**方向 (符号) を持たない**。構造上の範囲は −0.10〜+0.35 で、負になるのは range が
広がり (`grv_lock` = 0)、かつ SMA 系 2 項が食い違う日に限られる。147 日の値は最小 0.000、中央値 +0.114、
最大 +0.226 で、`e_star = e_raw + gravity_bias` に**一度も下向きに働かなかった** (v2 spec §6.3 は「小さく、
v2 の主因ではない」として係数調整を後回しにしていた)。α での効き方 (gravity を 0 にした replay との差):

| 変化 (gravity なし → あり) | N | gravity ありの的中 | gain (bp) |
|---|---|---|---|
| flat → up | 28 | 20 | +47.4 |
| down → flat | 11 | (flat は常に外れ。gravity なしなら 3 的中) | +28.1 |
| 計 | 39 | 差し引き +17 的中 | **+75.5** |

- 4〜11 月は上昇日が 65% なので、無条件の上向きバイアスが的中と誤差の両方を稼いだ。**信号ではなく
  ドリフトへの賭け**で、下落基調の月には同じ大きさで損失になる。10 月は gravity が 10/14 (外れ)・
  10/19 (的中)・10/22 (−86.6bp の外れ) の 3 本の up を作り、10/30 の down (的中だった) を flat に変えた —
  10 月に限ると gravity を 0 にした方が α の平均誤差は 0.79bp 小さい。
- 符号化 (`gravity × q_direction`) も 0 にする案も replay で方向・誤差とも悪化した (§4)。現状は変えず、
  CC-M07 として監視する (§8)。

## 9. 制限事項

- **標本は小さく、ドリフトに偏っている。** 147 日・非 FLAT 109〜119 本で、上昇日が 65%。§2 の「入力は情報を

  月別の効果 (±1bp 以内) は月内の数日で符号が変わる大きさ。
- 4〜7 月は現行 engine での再計算で、当時の本番 (v2〜v2.5) の forecast とは照合していない。照合済みは
  8/3〜11/6 の 272 件。

  組み直した replay。repo の script は mode A〜E を持ち (§4.2 の C / D / E と §5 の A / C / E は script の出力と
  一致を確認)、照合は本 PR から許容誤差なしの完全一致。AL1・G0・Gs は採用しないため script には入れていない。
- E の改善の大半は一律縮小と同じ効果である (§4.4)。0.75 は 9 月に事前登録した値をそのまま使い、本レビューで
  係数を探索していない — 探索すれば in-sample の数字はもっと良く見えるが、それは採用根拠にならない。
- counterfactual は magnitude 経路の変更が方向入力に影響しない前提に立つ (v2.5 以来の設計不変量。E では
  方向・FLAT の同一性を 588 件で検査済)。
- 執行層のドリフトは 21 窓。遅延 (+4h〜+10h) との関係は分けて測っていない。
