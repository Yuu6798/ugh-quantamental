## 何が外れたか — 9/10・9/14・9/25

governance 窓 19 日で UGH (α) が random_walk に負けた合計 **+140.9bp のうち、9/10・9/14・9/25 の
3 日で +148.1bp**。残り 16 日はネットで UGH が勝っている (−7.2bp)。方向を外した日は他にも
あるが (9/4・9/15・9/16・9/18)、賭けが小さい (|予測| 6〜20bp) ので差は +7〜+20bp に留まる。
**差を作ったのは「外したこと」ではなく「外した日の賭けの大きさ」**である。

3 日に共通する機序 (findings §4):

1. 直前 1〜3 窓が同方向の大きな動き (9/10: −102 → −25、9/14: −54、9/25: 4 連騰)。
2. その日の 3 つの方向入力 — `fundamental_score` (spot vs SMA20)、`technical_score` (SMA5 vs
   SMA20)、`price_implied_score` (前日変化) — が**機械的に同符号に揃う** (fundamental は 3 日とも
   ±1.0 に飽和)。この 3 つは独立ではなく、2 つは SMA20 からのスプレッド、1 つは前日変化で、
   ショック後は必ず揃う。
3. engine の alignment はこれを「3 つの異なる根拠が一致した」と読み、conviction を 0.75〜0.98 に
   上げ、magnitude 係数 (0.5 + 0.5 × conviction) が上限近くに達する。
4. さらに v2.5 の `_volatility_expansion_multiplier` (catalyst・urgency・fire の平均が高い = 大変動
   直後) が **×1.23〜×1.62** を掛ける。

**相関した情報を 3 回数えて確信を作り、その確信で賭けを最大化し、拡張項でさらに増やす** —
8 月の代表的失敗 (8/10、conviction 0.94、−39bp → 実現 +98.9bp) を含む Aug–Sep の最悪 4 日
すべてに共通する。conviction ≥ 0.9 の日の的中は 9 月 2/4 (RW 比 +89.5bp)、0.7〜0.9 は 0/1 で、
7 月レビューの「conviction ≥ 0.7 で 86%」は平時 (4〜7 月) の性質だった。

### FLAT の 2 日 (9/3・9/7) は別の現象

月間最大の外し 9/3 (−181.5bp、α/γ/δ flat) と 9/7 (−102.0bp、全 variant flat) は、conviction でも
epsilon でも trailing 幅でもなく、**1 日の反発 (`price_implied_score`) が 5〜20 日のトレンド項
(SMA 系) を打ち消して `e_star` 自体がゼロ近傍になった**結果 (findings §2)。9/7 は α −0.120 /
β +0.103 と variant 間で符号が割れており、閾値で救うことはできない。engine 改変の対象外。
