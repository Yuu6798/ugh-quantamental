## 相場コンテキスト (公開情報)

**本節は事後追記** (2026-08-09、`fx-market-context` skill 新設時)。初版はこの節を
欠いたまま「8/3 のセリングクライマックスで底打ち」と価格構造のみで判断していたが、
公開情報は**当局介入**を示しており、読みが変わる。

### 何が動かしたか

- **【確認済み】日米協調介入** — 米国が日本の為替介入に参加したことを Bessent
  財務長官が確認。「無秩序な円の動き」への対抗が目的とされる。
  ⚠️ **日付は未確定**: 出典は「Friday (August 2)」と書くが、2026-08-02 は日曜で
  8/3 が月曜のため、記事の曜日/日付が整合しない (7/31 金の可能性)。**介入があった
  事実は複数ソースで確認できるが、実施日は本レポートでは断定しない。**
- **【報道ベース】7/30 の当局介入疑い** — 163 割れの急落直後から介入観測が出たが、
  当時は公式確認なし。
  ⚠️ 初版は「エンジンの `intervention_risk=high` と報道が一致 = 独立 2 経路の
  裏付け」と書いたが**誤り**。この label は直近の実現終値変化の大きさだけで決まり
  (>100bp → high)、政策情報を含まない。7/30 が high なのは −236.9bp だったからで
  あって、介入を察知したからではない。**同じ事実の言い換えであり裏付けではない。**
- **【報道ベース】キャリートレードの巻き戻し** — 163 を明確に割ったところで、
  ドルロングのストップとマージンコールが連鎖。日銀の利上げ・国債買入縮小と、
  米指標の弱さによる FRB 利下げ期待が金利差を縮め、円資金調達キャリーの解消を
  誘発したとされる。

### メカニズムか、センチメントか

**構造要因**。介入は一時的な措置だが、その背後にある日米金利差の縮小と
ポジション解消は継続性を持つ。報道でも「介入は無秩序な動きを止め一方向の
ポジションを減らしたが、円安の主因である金利差は残っており、介入だけでは
一時的な緩和にとどまりうる」との評価。

### 価格構造の読みをどう修正するか

初版で「8/3 の下ヒゲ 195pips / 実体比 0.03 = 売り枯れによる底打ち」と書いたが、
**この解釈は撤回する**。撤回の理由は 2 つある: (a) この期間に当局介入があったこと、
(b) そもそも**下ヒゲの形状から「売り枯れ」という原因を読み取ることができない**
(同じ形は介入でも、大口の一時的な売りでも、薄商いでも生じる)。

⚠️ **ただし介入の向きを取り違えないこと**: 円買い介入は USD 売り / JPY 買いで
**USDJPY を押し下げる**。したがって介入は 163→155 の下落の原因候補であって、
**8/3 の安値を支えた要因でも、その後の反発の説明でもない**。反発の原因は
公開情報からは特定できていない (介入の停止、ショートカバー、別の材料のいずれも
あり得る)。初版はここを「介入が底を支える」と誤って書いていた。

8/4–8/6 の反発 (実体比 0.67–0.69 の陽線) 自体は事実だが、**その原因は価格からも
公開情報からも特定できていない**。戻り 36.6% で 38.2% 戻し (158.56) の直下に
止まっている事実は変わらないが、「底打ち確認」と読むべきではない。

なお、円安の主因とされる日米金利差は介入では変わらない (報道の評価も同旨)。
つまり **155–158 という水準が構造的に支えられている根拠はない**。

## 今週の構造的観測: v2.6 は効いた。ただし 20 窓平均が暴落を引きずる

### 効果 (設計どおり)

Range 100% は PR #122 のリプレイ予測 (全体 95%、<30bp 帯 100%) と整合する。今週の
実現変動は全日 |Δ| ≤ 43bp で <30bp〜30-100bp 帯に収まっており、**v2.6 が最も効く
レンジの週**だった。旧構成なら 30bp 超の 2 日 (8/4 +35.0、8/6 +43.1) は確実に
外していた (7 月の同帯は 0/28)。

### 副作用 (新規発見)

半幅は `trailing_mean_range_price × 1.25` で、この統計は **直近 20 窓の単純平均**。
7/30 の 577pips が母数に残っているため、レンジが実態より大きく膨らんでいる:

| | 値 |
|---|---|
| 8/3 の expected_range 全幅 | **259pips** (156.28–158.86) |
| 逆算した `trailing_mean_range_price` | 103pips |
| 今週の実際の日次レンジ | 8/4 **80** / 8/5 **60** / 8/6 **101** pips |

平常日の 2〜4 倍の幅で「100% 的中」しているため、**包含率は達成しているが情報量は
薄い**。これは v2.6 の設計 (95% カバレッジ狙い) の帰結であり欠陥ではないが、
**暴落 1 日が 20 営業日にわたってレンジを緩め続ける**という性質は spec に書かれて
いない。8/27 頃まで続く。

対処候補 (次の較正論点): 単純平均を **中央値または trimmed mean** に替えれば、
テール 1 日の寄与を構造的に抑えられる。包含率をどれだけ落とさずに幅を締められるか
は、次の月次レビューで v2.6 の実データが 1 ヶ月分揃ってから検証するのが妥当。
**今すぐ触るべきではない** — v2.6 はまだ 4 観測日しか経ておらず、母数が足りない。

### 方向側は未解決

エンジンは 7/30 の暴落後、**8/3–8/7 の全日で state=fire、e_star も一貫して
マイナス**だった (conviction 0.35–0.71)。ただし**出力方向は variant で割れており**、
β/δ は 8/5 と 8/7 に FLAT を出している (epsilon 判定が小さな負値を FLAT に落とす)。
「生シグナルが弱気で固まった」ことと「全 variant が down を出し続けた」ことは
