## 今週の構造的観測: 強トレンドでの magnitude / state 追随の遅れ

- **magnitude**: +42.5bp / +44.1bp の実現に対し期待変化は +5〜6bp。v2.5 の magnitude 拡張
  (ボラ拡張項) はこの 2 日で有意に作動しておらず、続伸局面の 2 日連続 under-call となった。
  レンジ miss も同 2 日に集中 (「大きめの実現変動時にレンジが外れる」パターンが 3 週連続)。
- **state**: `state_correctness_hit` 0/4 (先週 75%)。実現 state 分類 (OHLC 由来:
  quiet→dormant / large+strong body→fire / moderate+strong→expansion) に対し、予測
  dominant_state は全日 setup に滞留 (persistence 100%)。上昇続伸日の実現は expansion/fire
  側に振れており、「方向は当てるが state 遷移 (setup→fire) を先取りできない」形。
  7/13 週の stC 75% は小動き週で setup=setup が並んだ結果であり、**stC は
  「実現レンジ幅の regime を先読みできたか」の指標として機能し始めている** (magnitude
  under-call と同根の現象を state 側から見たもの)。
- **conviction の逆行**: +42.5bp 的中翌日の 7/22 に conviction が 0.86 → 0.50 へ低下し、
  以降 0.63 → 0.49 と続伸中も伸び悩み。大変動後の減衰 (hysteresis) がトレンド継続局面では
  慎重側に働いている可能性があり、magnitude under-call と併せて月次再検証の観測対象。
