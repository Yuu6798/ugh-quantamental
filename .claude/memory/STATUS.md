4. **9/7 FLAT の成分分解 (9 月月次・最優先)** - epsilon は **固定 3.0bp** (v2.6 は epsilon 2 フィールドを上書きしない)。FLAT 条件は `|e_star| × trailing_mean_abs_close_change_bp × (0.5+0.5×conviction) ≤ 3.0bp`。順序厳守: **(i)** 9/4→9/7→9/8 の `pre_expansion_close_change_bp` を (a) e_star / (b) trailing 幅 / (c) conviction に分解 (9/7 の conviction は 0.319、翌日 0.977 で係数は 2/3)。**(ii)** (a) を示した場合のみ e_star 自体を分解 — `compute_e_raw` = direction_signal (u/technical/price_implied 重み付き和) × conviction_multiplier × alignment、`compute_e_star` は gravity_bias を加算。**momentum_5d はこれら入力の上流の 1 要素にすぎない**。**(iii)** そこで初めて epsilon × 当該パラメータの 2 次元評価。**`analyze_estar_lag.py` は現状のままでは使えず、前提タスクが 4 つ**: 窓のパラメータ化 (`ANALYSIS_END`/`SEARCH_END` が 2026-08-28 固定、CLI 上書き無し) / `pre_expansion_close_change_bp` と 3 成分の算出・出力 (`conviction` は参照すらしていない) / ablation 軸に e_star 入力項を追加 (現状は生統計 3 本のみ) / daily series の全 variant 化 (現状 alpha のみ)。
